Open Source · Monorepo · 100 GB Ready

Aurora File Bucket

Transferencia fragmentada, comprimida y reanudable de archivos masivos de hasta 100 GB hacia servidores Windows Server (IIS + ASP.NET), con clientes nativos en .NET y Python y autenticación OAuth con Google.

Leer especificación técnica Ver contrato OpenAPI

Receptor ASP.NET + IIS

Streaming directo a NTFS sin buffering en memoria, bóvedas aisladas, limpieza inmediata de staging y panel SignalR en vivo.

Clientes Windows y Linux

Emisores en .NET 8/9 y Python 3.12+ con compresión adaptativa Zstandard, token bucket y reanudación persistente en SQLite.

OAuth Google + Token Rotativo

Inicio de sesión con cuenta de Google (PKCE) y rotación automática de JWT entre bloques para cargas de varias horas.
